# 社区地下车库防汛挡板部署与归位系统

管理车库入口、挡板分段、立柱、密封条、存放架、预警等级、部署任务、现场人员、
安装照片、积水观察、拆除清洗与缺件补充。**零第三方依赖**，Python 3.10+ 标准库即可运行。

## 一条命令启动（载入部署 / 缺件 / 提前解除三个样例）

```bash
python3 -m flood.app --demo
# 打开 http://127.0.0.1:8000
```

可选参数：`--port 8000 --tick 5`（天气复查节拍秒数）`--db data/flood.db --photos data/photos`。
空白库启动：`python3 -m flood.app`。

## 业务流程与规则

```
预警达黄警 → 按入口自动生成部署清单（挡板+密封条+立柱）
领件扫码锁定（同件器材跨入口排他；宽度不符判“挡板错段”拒绝）
齐套进入安装 → 逐段确认 连接(安装工)/密封(安装工)/通道封控(保安)，可拍照
→ 安装完成整体封控（并发完成仅生效一次）
预警连续2拍复查低于黄警才解除 → 拆除（积水≥15cm 禁止；未解除须主管批准）
→ 清洗拍照 → 晾干拍照 → 建立归架盘点单 → 逐件扫码
→ 核对差异（缺件/破损须承认）→ 物业主管报损并同规格补件 → 结案，器材重新可用
```

专项处置：

- **临时车辆放行**：仅保安可开，开启后该段连接/密封/封控全部失效，复位后须重新逐段确认。
- **密封条破损**：旧条下架，自动换库内备用条并重置密封确认；无备用条需先补充。
- **人员迟到**：超过应到时间签到自动登记迟到异常。
- **入口积水**：≥10cm 记异常，≥15cm 阻断拆除；监测设备水位由调度按雨量地势推算写入。
- **归架缺件**：盘点差异显式承认后，主管报损 + 同规格补件顶替，器材状态恢复可用。

## 七个页面

预警看板（含简洁线形雨量趋势、异常清单、天气注入控制）、入口示意图（按实际拼接顺序
横向排列，缺段为橙色虚线**空槽**，圆点显示三段确认）、器材领用、分段安装（移动端
**大勾选区 + 底部固定拍照入口**）、积水观察、拆除清洗、归架盘点。
配色：混凝土浅灰 `#e8e9eb`、雨水蓝 `#1f6fb2`、警戒橙 `#f26a1b`。

## 技术结构

- `flood/db.py` — SQLite 建表/连接（WAL + 进程锁，关键事务 `BEGIN IMMEDIATE` 保证排他）
- `flood/service.py` — 全部领域规则
- `flood/weather.py` — 模拟适配器（确定性降雨脚本 + 人工注入 + 地势水位推算）
- `flood/scheduler.py` — 进程内定时线程：预警升级、清单生成、连续复查解除
- `flood/seed.py` — 三类样例数据
- `flood/app.py` — `http.server` JSON API + 静态页 + multipart 照片上传（存本地目录）
- `flood/static/` — 单页前端（原生 JS + SVG 雨量线图）
- `tests/test_flood.py` — 规则测试
