# 社区地下车库防汛挡板部署与归位系统

围绕一次预警轮次，管理车库入口的防汛挡板「部署 → 守看 → 拆除 → 清洗 → 晾干 → 归架」
全流程。人员与天气使用演示数据，SQLite 持久化器材与任务，本地目录保存现场照片，
进程内后台任务驱动预警升级与复查，模拟适配器返回雨量与水位。

**零第三方依赖**，仅使用 Python 3.10+ 标准库。

## 一条本地启动命令

```bash
./run.sh                # 重置数据并载入三类演示样例，默认 8000 端口
PORT=8080 ./run.sh      # 自定义端口
SCENARIO=storm ./run.sh # 切换天气脚本（yellow / storm / recede）
```

等价于：

```bash
python3 -m app --reseed --host 0.0.0.0 --port 8000 --scenario yellow
```

启动后访问 <http://localhost:8000/>。启动时载入三类样例：

| 样例 | 入口 | 状态 |
|---|---|---|
| 部署中 | 东门（4 段） | 黄色预警，已领件，前三段安装确认、**第 4 段缺段空槽**，含人员迟到事件 |
| 归架缺件 | 西门（3 段） | 晾干上架待盘点，**SEAL-03 胶面撕裂**，待物业主管报损补充 |
| 提前解除 | 北门（2 段） | 已由主管批准提前拆除并完成全闭环，预警记录为提前解除 |

右上角可切换当前岗位（保安 / 防汛员 / 物业主管），权限会随之变化。

## 七个页面

1. **预警看板** — 当前等级、雨强/水位、紧凑雨量趋势线、各入口处置进度、缺件补充单、事件流水；可切换天气脚本、手动复查、快进时间轴、正常/提前解除。
2. **入口示意图** — 挡板按实际拼接顺序自左向右横向排列，立柱夹于段间，**缺段位置为橙色虚线空槽**，附最近积水水位条。
3. **器材领用** — 按入口清单领件，锁定挡板/立柱/密封条；库存实时显示占用任务。
4. **分段安装** — 移动端大勾选区逐段确认「连接 + 密封」；支持错段换板、密封条破损自动换备件；保安执行通道封控与临时车辆放行/重封；底部**固定拍照入口**。
5. **积水观察** — 封控守看期间记录水位（≥10cm 自动警戒）、说明与照片。
6. **拆除清洗** — 预警解除方可拆除；**物业主管审批提前拆除**；拆除→清洗→晾干→上架节点推进。
7. **归架盘点** — 逐件核对在位/缺失/损坏；**缺损件由主管报损开补充单**，新器材入库恢复可用；全部处理后完成归架。

## 业务规则

- **器材排他**：一件器材同一时刻只能属于一个入口任务；`BEGIN IMMEDIATE` + 进程锁保证并发领件分配不重叠，失败不留半锁定。
- **分段完整**：所有槽位「连接 + 密封」均确认后才允许封控；错段换板后必须重新确认；密封条破损自动领用备用条，无备件则挂缺件。
- **预警状态**：蓝/黄/橙/红按雨强（mm/h）与水位（cm）阈值判定，等级只升不降，连续 3 次安全复查方可正常解除。
- **权限**：保安执行封控与放行；防汛员安装确认；**物业主管决定提前解除、提前拆除审批与缺件报损**。
- **拆除控制**：预警未解除且无主管审批时禁止拆除（防拆除过早）。
- **归架差异**：存在未报损的缺/损件不能完成核对；并发完成只生效一次（条件更新兜底）。
- 临时车辆放行后必须重新封控确认；人员迟到登记事件并安排顶替，不阻塞任务。

## 天气模拟

`app/weather.py` 内置三段脚本：`yellow`（黄色持续）、`storm`（蓝→黄→橙→红→回落完整过程）、
`recede`（雨停解除）。后台每 15 秒自动复查（升级时自动为全部入口生成部署清单），
看板上也可手动「立即复查」「快进 90 秒」。

## 数据与照片

- SQLite 数据库：`data/garrison.db`（`--reseed` 时重建）
- 现场照片：`data/photos/`，安装/观察/封控/重封时通过移动端拍照或文件选择上传

## 测试

```bash
python3 -m unittest discover -s tests
```

27 个用例覆盖：

- **器材排他**：跨入口并发领件不重叠、同任务并发只成功一次、库存不足原子失败、全流程状态
- **分段完整**：未齐拒绝封控、保安/防汛员权限、错段纠正重确认、密封条破损换条/无备件挂缺
- **预警状态**：阈值判定、只升不降、复查解除、自动生成清单、积水警戒、放行重封、迟到不阻塞
- **提前拆除审批**：未解除禁拆、仅主管可审批且需原因、审批后拆除闭环、正常解除后拆除
- **归架差异**：未盘点/未报损不可完成、主管报损与补件入库、器材恢复可用、**并发完成仅一次**

## 目录结构

```
app/            后端（标准库）
  db.py           SQLite 建表与连接
  services.py     领域服务与全部业务规则
  weather.py      模拟天气适配器 + 进程内监控线程
  queries.py      只读聚合查询
  server.py       HTTP/JSON API、照片上传、静态资源
  seed.py         演示样例数据
  photos.py       占位现场照片生成
web/            前端（原生 HTML/CSS/JS，无构建）
tests/          unittest 测试
run.sh          一条启动命令
```
